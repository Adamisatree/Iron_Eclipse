# 铁蚀战线 GDD — 游戏设计文档 (完整版)

> 版本 0.9.0 | 构建 d555555 | 2026-10-27

## 1. 愿景与定位
重型机甲团队竞技，关键词：重量感、热量管理、推进器机动、队伍协同。PC 端 Windows + macOS 跨平台，局域网零配置，轻电竞向。

## 2. 核心循环
大厅选机 → 读秒3-2-1 → 90s交火/占领/运核 → 回合胜负 → 3胜晋级 → 结算经验/解锁 → 返回大厅。

## 3. 机体设计原则
- 高度 6.8–8.5m，重量感来自比例/声音/镜头/动作，不是慢
- 角色分工：TANK/SNIPER/SUPPORT/STRIKER/MISSILE/ASSAULT
- 数值同框架池，阵营仅外观

## 4. 资源系统
Armor / Structure / Shield (脱战3s回) / Heat (满100强制散热1.5s) / Boost (1s后回) / Stagger (阈值1.2s硬直可处决) / 弹药 (弹匣+备弹，能量武器用热量)

## 5. 战斗数值
详见 README 伤害公式与 data/Definitions。交火距离 20–80m，重型5.5–6.5/中型7–8/轻型9–10 m/s，冲刺1.2s 14–24 m/s 35能量，跳跃2.5–4m，重武器前摇+热量。

## 6. 模式
见 README。中央维修点占领回15%装甲；相位核心持核-15%移速可掉落；处决需硬直且结构<20%，1.5s可打断。

## 7. 地图
4 张地图各有主题，3+2+1 路径结构，6掩体2高点1中心目标，3s出生保护，不可直视敌方出生点，局部可破坏。

## 8. 进度
本地存档：等级/解锁/涂装/贴花/数据核心。竞技数值全解锁，解锁仅外观/训练模块。经验来源：伤害/承伤/目标/胜利/助攻。最近20局本地保存。

## 9. UI/UX
主菜单 战役/局域网/训练/机体库/设置；局域网页房间自动刷新+直连IP+建房+密码+版本；大厅两队+房间设置+聊天+准备/开始；HUD 左下装甲结构护盾 右下热量弹药推进 中央准星命中反馈 上方队伍硬直 交互击杀；结算 胜负/数据/经验/解锁。

## 10. 可访问性
字幕/色盲模式(形状区分敌我)/屏幕震动开关/动态范围压缩。

## 11. 音频
工业合成器+分层鼓点+低频贝斯，劣势加警报层；机甲伺服/液压/脚步/推进器/散热；武器区分度。

## 12. 美术标准
LOD0 80k–150k, LOD1 40k, LOD2 15k, LOD3 5k；英雄4K其他2K Trim Sheet；通道 BaseColor/Metallic/Roughness/Normal/AO/Emissive/DamageMask；磨损边缘掉漆/油污/熏黑/划痕；模块插槽肩背左右腰涂装贴花。

## 13. 动画
30FPS采集插值，移动代码驱动，近战根运动+Motion Warping；骨骼 Root→Pelvis→Spine→Chest→Neck→Head 等；IK 双脚/左手/瞄准/后坐力/受击平衡；状态机 基础/瞄准/武器/推进/空中/受击/近战/死亡；重量感脚步震动/液压蓄力/惯性滑步/后坐/热浪扭曲。
